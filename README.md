## Description

**homepage** is a simple minimalistic start page for browser, it works as an html page with some nice features for customizations. it should work flawlessly on any device, but this is yet to see.
## Installation

You can get **homepage** running by:

1. download the source.
2. move it in a place you like.
3. select the index.html as your default "new tab" in your favourite browser.
4. done!


    
## Features

i've tried my best to keep this project to just the most essential features based on my needs.

- Groups
- Icons
- Themes
- Search bar
- Easy JSON customization

More throughly

### **Groups**

you can add as many groups as you like, as of right now no options to add icons to them (sorry).

### **Icons**

you can add links to a group with a:

- Name
- Icon
- Description

and icons are either availble thru **favicons** or **local file**

### **Themes**

there are multiple themes to choose from, and i will be adding many more, everything is listed in a doc.md file.

### **Search bar**

There is a search bar which is customizable to add a query from your favourite search engine.

### **Easy JSON customization**

Thanks to the "Import JSON" function there is no need to edit that pesky html which we all hate! Everything is configurable via a JSON file which you import, the website will keep it until you import another so you don't have to always upload the configuation.
## JSON documentation

As i said before everything you need to configure is in the JSON, all the documentation can be found in doc.md
